# 外观切换

2026-10-27：依照用户确认，使用 theming-system 与 minimalist-ui 新增「纸白极简」，同时保留「像素宇宙」。随后按用户选择的 1、3、4 方案，使用 terracotta、dark-blue-contrasting-clean、riso 新增三套皮肤。

## 使用

进入 `/pixel-schedule.html`，右上角「外观」可切换六个页面及弹窗的皮肤。首次默认像素宇宙；选择保存在当前浏览器的 `cinema.appearance`，刷新后恢复，同源标签页同步。存储不可用时仍可当次切换。白色原版 `/` 和旧样机独立保留。

### 原版入口统一

右上角新增第六项「原版」，原版 `/` 和 `/index.html` 也加载同一外观菜单，便于往返。选择原版实际进入 `/#当前页面`；从原版选择其他外观进入 `/pixel-schedule.html#当前页面`，六个页面路由均保留，未知路由回日程。原版不加载像素 CSS、像素图标适配器或复古新建流程，因此保持真正的原版布局与交互。

注意：原版与五套皮肤之间属于整页导航，会重新载入，未保存输入应先保存；菜单中已标记「切换页面」。五套皮肤之间仍即时切换并保留节点、草稿和时间轴位置。跨标签页的偏好同步不会触发跨入口导航，避免使其他标签丢失正在输入的内容。显式访问原版 URL 始终显示原版，显式访问像素 URL 时恢复上次有效的非原版外观，否则默认像素宇宙。

### 外观菜单动效

用户最终确认：与「外观」按钮在同一行，所有选项横向向左展开。按 emil-design-eng 与 animation-principles 实现：固定定位在按钮左侧，顶部与按钮对齐，留 12px 间隔；选择条与按钮等高（通常 44px），最长 700px。六个选项保持单行，以小色样＋名称呈现，不再使用竖向预览卡片网格。

- 鼠标打开：右边缘中心为变换原点，从右侧 14px、96% 大小和透明过渡到原位，180ms，`cubic-bezier(.23,1,.32,1)`。不使用向下移动。
- 六个选项由右到左依次出现，间隔 20ms，以 8px 横向微移和透明度变化呈现。悬停微抬 1px，选中显示勾。按钮按下缩至 96%。
- 窄屏仍为单行，支持触摸、触控板横向滑动及鼠标滚轮横向浏览；打开时将选中项滚到可见范围，不移动页面。详细外观说明保留在选项悬停提示中，选择条标题仅供辅助技术读取。
- 鼠标关闭：120ms 向右收回，结束后才隐藏；退出期间立刻禁止面板交互。
- 快速反向：先读取当前动画姿态再取消，下一次从当前帧继续，旧完成回调不能隐藏重新打开的面板。只改变 transform/opacity，不重建卡片或应用内容。
- 键盘、Escape、焦点离开及减少动态偏好即时响应；关闭时适当把焦点还给外观按钮。外部鼠标点击保留退出动效。页面滚动时跟随按钮定位，按钮离开视口后关闭。

覆盖原版及五套皮肤，材质、重点色和勾选颜色沿用当前皮肤，不引入额外粒子或屏幕闪烁。

### 新增皮肤的设计基准

| 外观 / 存储值 | 背景 / 面板 | 正文 / 重点色 | 特征 |
| --- | --- | --- | --- |
| 奶油陶土 / `clay` | `#f3e9d8` / `#fffaf1` | `#423025` / `#a7512c` | 宋体展示标题、奶油纸色、细分隔线、轻微纸层阴影 |
| 午夜蓝 / `midnight` | `#0b1222` / `#111e33` | `#eaf0fc` / `#91b1ff` | 深蓝分层、钴蓝标题区和操作按钮、局部柔光，无扫描纹或星空 |
| 双色印刷 / `riso` | `#f7f1e6` / `#fff9ef` | `#2c40a7` / `#b32370` | 深蓝文字、玫红交互、纸色底、细边与 2–3px 套印阴影 |

双色印刷按钮采用 `#f237a1` 及深色文字，避免亮粉底白字对比不足。印刷效果不作用于正文，不模糊或错位文字。午夜蓝不使用浅纸色输入框或遗留的琥珀文字。长标题仍用现有换行、横向滚动与聚合规则；皮肤不重排时间坐标。

## 视觉边界

- 像素宇宙继续遵守《视觉风格与动效复用规范》；其材质、浅弧轨道、局部动效不被新皮肤覆盖。
- 纸白极简：暖白 `#f7f6f3`、白色面板、炭灰 `#2f3437`、陶土色 `#ad6248`；平整表面、浅细边、系统字体及简洁实心图标。隐藏星空、扫描纹和荧光。评分条保留表示数值比例的双色填充。
- 皮肤切换只更新根元素 `data-theme`。布局、时间轴几何、聚合展开、固定详情、评分惯性、隐私、海报、逐级新建和拖放业务共用原实现。长按收合保留现有结构与时序，纸白主题使用低饱和像素格。
- 切换用 200ms 透明度过渡，减少动态偏好下关闭该过渡。无页面刷新、不重建应用节点、不调用保存接口，因此保留当前草稿和时间轴位置。切换不会触发重新入场。

## 实现

- `frontend/appearance.js`：首屏读取偏好、切换器、焦点与 Escape/外点关闭、跨标签页同步。切换器位于稳定页眉，独立于导航时替换的身份区域。
- `frontend/appearance.css`：选择器及纸白主题变量、遗留固定色覆盖；仅作用于带 `pixel-theme` 的入口。
- `frontend/pixel-schedule.js`：同一 SVG 内提供像素和简约两套图形，通过主题选择显示，不重建业务界面。
