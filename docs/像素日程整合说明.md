## 缩放性能修正

按 `animation-performance` 检查发现：最初适配器逐个读取 offsetLeft / offsetWidth 并立即写入影响 margin 的样式，形成布局读写交错；所有屏外节点也参与。现缓存节点的日期表达式，常规缩放通过数学计算横坐标；所有场景尺寸先读完再批量写入，只更新位置有变化的节点，缓存相同轨道路径，并忽略详情区无关的 DOM 变化。未知位置表达式保留实时几何回退，避免为性能牺牲定位正确性。

保留 margin 的单批次写入，以免抢占原版悬停 transform、聚合展开 translate 动画；未加全局 will-change 或禁用动画。400 节点模拟测试验证稳态布局读取不超过 5 次、没有读写交错、屏外与未变节点跳过。此项不等同于实机 FPS／GPU 性能测量，需在用户设备继续对比。
