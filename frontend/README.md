# 共映 · 前端风格预览

根据 brand-design-system.zip 中的 Minimax DESIGN.md 制作。白底、蓝色强调、胶囊导航、20–24px 圆角卡片、轻紫色阴影与大留白。

运行：在此目录执行 `node server.cjs`，打开 http://127.0.0.1:4173。

当前以 Notion 风格表格为主，包含看板、画廊、时间线与可选显示列。添加作品支持站内搜索豆瓣候选，按片名、年份、原名和可获取的导演资料核对版本；点击候选后自动关联豆瓣、带入资料，无需粘贴链接。详情访问受限时保留候选的片名、年份与原名，其他资料可手动补全。找不到时可直接手动添加。新增作品保存在当前浏览器 localStorage，刷新后保留，不会跨设备同步。清除网站数据会丢失新增记录。

豆瓣访问限制可能导致资料读取失败，此时保留关联链接并允许手动补全；评分标明来源，不保证实时更新。双人登录身份与服务端隐藏权限仍未实现。封面为占位插画。

表格点击「选择」进入勾选模式，支持逐行选择、全选、反选和清空，再批量删除。全选与反选仅作用于当前筛选结果，切换筛选会取消不可见作品的选择。删除前显示数量和片名进行确认，整批移到回收站后可立即撤销本次删除，或从回收站逐条恢复。回收站保存在当前浏览器，刷新后仍保留；不会永久清除电影资料。

表格评分、状态、年份、类型、语言、观看日期、短评、优先级、添加人和计划日期支持点击单元格编辑；片名旁的 ✎ 可改名。Enter 保存、Esc 取消（短评 Shift+Enter 换行）。评分允许 0–10 分、最多一位小数，留空清除，双方分别保存。豆瓣评分为只读来源资料。编辑数据保存到浏览器 `gongying.filmEdits.v1`，也适用于原始十条作品；回收站恢复后仍保留修改。

新添加作品与原始记录通过 `film-metadata.js` 共用资料字段规范。页面加载时按已关联豆瓣 ID 补全缺失资料；用户编辑优先，个人评分、观看日期、短评和删除状态不会被豆瓣资料覆盖。原名保留来源语言，未读取到的资料不编造。原始片名保留用户录入值。

测试：`node --test *.test.cjs`。

添加表单（包括手动添加）提供「查找并补全资料」：先填写片名或原名，服务端通过 `/api/metadata/search?q=` 实时搜索 Wikidata，展示年份、导演、原名和版本说明。选择正确候选后仅填空白的片名、年份、原名、导演、类型标签、语言和地区，保留用户已经填写的内容；候选年份与已填年份不同时拒绝填入并提示核对。资料源没有的字段继续手填，不编造简介或英文名，不创建豆瓣关联或评分。补全资料随新增记录保存在 localStorage；补入的原名带来源链接。查询使用固定 Wikimedia 域名、请求超时及大小限制、3 分钟内存缓存；Windows 使用系统 curl 网络配置。服务不可达和未找到条目有不同提示，都允许继续手动添加。

已核对的缺失名称由 `supplemental-metadata.cjs` 使用维基百科、Focus Features、电影网补充，按既有豆瓣 ID 匹配；原始未关联的《登堂入室》补入维基百科名称资料，但不伪造豆瓣关联或评分。名称来源可在影片详情查看。本次是核对后的资料快照，不代表所有电影已实现自动跨站检索。《太阳伞》仅显示已核对的中文原名，未编造英文发行名。

中文采用系统字体，英文字体 DM Sans / Outfit 通过 Google Fonts 加载；网络不可用时使用本地字体回退。
