# 公开数据备份

经用户确认，当前数据快照随项目公开上传 GitHub。

- `personal-data-backup.json`：2026-10-10（北京时间）从本项目浏览器导出的四个存储键的原始字符串；`null` 表示当时该键不存在。当前新增影片、编辑记录和回收站均无保存内容，仅保存了隐藏内容列、语言列的设置。
- `film-records-snapshot.json`：已有十部电影、观看日期及当前代码里的豆瓣关联/资料快照。双方未填写的评分保持空值，豆瓣分数并非实时。

这是一次备份，不是自动同步。浏览器里的后续更改不会自行写入这些文件。可在本地 `/backup.html` 重新导出浏览器数据。

浏览器数据备份中的 `storage` 保留原始值和键名，可用于恢复到同一版应用；影片 JSON 是便于阅读的快照，不应直接当成新增影片存储导入，否则可能重复原始电影。当前没有自动导入/合并功能，恢复前需先备份目标浏览器数据。

公开仓库的备份任何人都可读取。即使以后移除文件，历史提交也可能保留内容。
